One sentence, 187 characters, that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun.

## The pitch

> Describe the app idea you've been carrying around for months to an AI agent on make.fun tonight, in plain words, and wake up to a working first version, no code, no cost, just your words.

## Run it

```sh
python3 main.py
```

Writes the pitch to `/output/entry.txt` (187 characters, UTF-8, one sentence).
